# SuperMartket

Aplicativo para organizar compras de supermercado em uma lista compartilhada entre familiares.

[**Acessar aplicação**](https://arthurnunesdev.github.io/SuperMartket/)

## Funcionalidades

- Acesso protegido por PIN e identificação por nome.
- Lista compartilhada com sincronização em tempo real.
- Cadastro, edição e exclusão de produtos.
- Subtotais, total da compra e histórico.
- Tema claro e escuro.

## Tecnologias

React, Vite, Supabase (Auth, PostgreSQL e Realtime) e GitHub Pages.

## Executar localmente

```bash
npm install
npm run dev
```

Para validar o projeto:

```bash
npm test
npm run build
```
